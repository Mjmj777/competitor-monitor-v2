# Competitor Intelligence Monitor v3

لوحة ثنائية اللغة لمراقبة عروض ومنشورات منافسي المدفوعات الرقمية، تعمل على GitHub Pages وتتحدث تلقائيًا من GitHub Actions.

## ما الذي تغيّر في هذه النسخة؟

- أسماء الشركات تظهر بالإنجليزية في الواجهتين العربية والإنجليزية.
- الفصل بين:
  - **Confirmed Offer:** عرض يقدم منفعة واضحة مثل خصم أو كاش باك أو جائزة أو إعفاء من الرسوم.
  - **Partner Discount:** خصم أو عرض مرتبط بتاجر أو شريك.
  - **Product Post:** منشور يشرح منتجًا أو خدمة من دون عرض فعلي.
  - **Awareness / General Post:** محتوى توعوي أو عام.
  - **Needs Review:** تصنيف أو رابط يحتاج مراجعة بشرية.
- عدد العروض الرئيسي لا يشمل خصومات الشركاء أو المنشورات العادية.
- نشاط القنوات يحتسب منشورات آخر 7 أيام لكل منافس ومنصة.
- الرسم الزمني يعتمد على تاريخ النشر الفعلي، ولا يعتبر الاستيراد الأولي نشاطًا حدث اليوم.
- صفحة مستقلة لكل منافس، ومعرض لأحدث الصور والفيديوهات المتاحة من RSS.
- صفحة تحليل داخلية لكل عرض أو منشور مع سجل التغييرات والإصدارات.
- تنبيهات محلية منذ آخر مرة ضغط فيها المستخدم **Mark all reviewed / تحديد الكل كمراجع**.
- الروابط العامة أو التصنيفات غير المؤكدة تظهر في قائمة المراجعة ولا تدخل في عدد العروض المؤكدة.

## التشغيل على GitHub

1. ارفع جميع الملفات مع المحافظة على المسارات.
2. من **Settings → Pages** اختر **GitHub Actions**.
3. افتح **Actions → Competitor Intelligence Monitor → Run workflow**.
4. بعد نجاح `build` و`deploy` افتح رابط GitHub Pages.

## منطق التصنيف

التصنيف موجود في `config.json` ويمكن توسيعه من دون تعديل الواجهة:

- `categories`: المنتجات والخدمات مثل International Transfer وCards وMusaned.
- `benefit_types`: نوع المنفعة مثل Discount وCashback وFee Waiver.
- `classification.partner_keywords`: مؤشرات الشراكة أو التاجر.
- `classification_overrides`: استثناءات يدوية حسب الرابط عند الحاجة.

> التصنيف آلي ومساعد للتحليل، وليس بديلًا عن المراجعة البشرية. أي عنصر منخفض الثقة يذهب إلى **Needs Review**.

## الروابط المباشرة

المراقب يستبعد رابط صفحة العروض العامة عندما لا يكون رابطًا تفصيليًا. إذا لم يعرض الموقع رابطًا مباشرًا داخل HTML، فلن يتم احتساب العنصر كعرض مؤكد، وسيظهر كمصدر يحتاج مراجعة بدل تضخيم العدد.

## الصور والفيديو

يستخرج النظام الصور والفيديوهات المتاحة داخل RSS أو HTML. بعض منصات التواصل لا توفر ملف الفيديو المباشر؛ في هذه الحالة تظهر الصورة المصغرة أو بطاقة تشغيل تفتح المنشور الأصلي.
